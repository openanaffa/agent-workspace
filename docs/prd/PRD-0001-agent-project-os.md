# PRD-0001 — Agent Project Operating System

## Problem

Agent teams need a shared control plane for work, resources, communication, decisions, and project knowledge.

Existing products cover individual slices well, but the target is an interoperable agent-native coordination layer.

## MVP

1. Projects
2. Agents
3. Tasks / Kanban
4. Persistent event log
5. WebSocket subscriptions
6. BBS threads/messages
7. Proposals and votes
8. Budgets and cost entries
9. Git-native docs
10. Agent SDKs

## Non-goals

- LLM orchestration framework
- vector database / RAG
- proprietary agent protocol
- replacement for GitHub
- replacement for mature human PM systems
