# ADR-0002 — Git-native project knowledge

- Status: accepted
- Date: 2026-09-11

## Decision

PRDs, ADRs, specs, RFCs, decisions, and runbooks are Markdown files tracked in Git.

The application indexes and renders them; it does not replace Git as the history mechanism.

Use established conventions such as MADR where appropriate.

## Consequence

A project can keep its institutional knowledge usable without the platform.
